std::unordered_map< std::string, VariableRanges > DataLoader::loadRanges ( const std::string &  filename)
static

Parses the ranges.txt file to extract variable live-range points.

Each non-comment line has the form:

varName: line1+, line2, line3-, ...

where + marks a definition and - marks the end of a live range. Multiple lines for the same variable create separate range segments.

Parameters
filenamePath to the ranges file.
Returns
An unordered_map from variable names to their VariableRanges data.
Exceptions
std::runtime_errorif the file cannot be opened or contains malformed lines.
Note
Time Complexity: O(L * P) where L is the number of variable lines and P is the maximum number of program points per line.

const std::string &  defaultDir 
)
static

Resolves a short filename to a full path by checking common directories.

Search order:

  1. The path as given (absolute or already correct relative).
  2. The current working directory.
  3. ../basic/<defaultDir>/<inputPath>
  4. ../../basic/<defaultDir>/<inputPath>
Parameters
inputPathThe filename or relative path to resolve.
defaultDirSub-directory inside basic/ where the file typically lives (e.g., "ranges" or "registers").
Returns
The first path that resolves to an existing file, or the ../basic/<defaultDir>/... fallback if none is found.
Note
Time Complexity: O(1) — at most four filesystem probes.
