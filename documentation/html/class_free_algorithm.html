Detailed Description

Register allocation using Kempe Chain swaps as a last-resort rescue to avoid spilling.

Runs the standard greedy graph coloring (Phase 1 simplification + Phase 2 coloring). When Phase 2 gets stuck (all N registers taken by neighbors of a node), it attempts a Kempe Chain rescue before falling back to spilling.

Kempe Chain Rescue

Given stuck node X with neighbors using every available color:

  1. Pick a target color c (used by neighbor A) and a partner color c2.
  2. Build the (c–c2) Kempe chain starting at A: the maximal connected subgraph containing only c- and c2-colored nodes that includes A.
  3. Validate: none of X's other c2-colored neighbors may be in the chain (swapping the chain would otherwise still leave X with a c neighbor).
  4. If valid, swap all colors in the chain (c ↔ c2). Color c is now free for X.

Attempt a Kempe Chain rescue for stuck node nodeId.

Iterates over all pairs of colors (c, c2) used by neighbors of nodeId. For each neighbor A with color c, builds the (c–c2) chain from A and validates that no other c2-neighbor of nodeId is inside the chain. On success, swaps the chain in-place and returns the freed color c.

Parameters
graphInterference graph.
nodeIdThe node that cannot be colored.
colorAssignmentCurrent partial color assignment (modified in place on success).
numRegistersTotal number of available registers.
Returns
Freed color index on success, or -1 if no rescue is possible.
Note
Time Complexity: O(N^2 * (V + E)) where N = numRegisters
