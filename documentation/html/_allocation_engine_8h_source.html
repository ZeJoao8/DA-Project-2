28 /**
29 * @brief Centralized algorithm dispatching, success checking, and output writing.
30 *
31 * Always attempts basic greedy coloring first. If basic coloring succeeds,
32 * the result is written and the function returns. On failure, the algorithm
33 * specified by `registerConfig.algorithmName` is invoked as a fallback.
34 *
35 * Supported fallback algorithms and their trigger condition:
36 * - `"basic"` : Reports failure; writes result with all webs in memory.
37 * - `"spilling"` : Runs Chaitin-style spilling (SpillingAlgorithm) with
38 * `registerConfig.algorithmParam` as the spill limit.
39 * - `"splitting"`: Runs iterative web splitting (Splitting) with
40 * `registerConfig.algorithmParam` as the split limit.
41 * - `"free"` : Runs Kempe Chain rescue (FreeAlgorithm).
42 *
43 * @param interferenceGraph The prebuilt interference graph (vertices = web IDs).
44 * @param webs List of all webs in the current allocation problem.
45 * @param registerConfig Configuration: number of registers, algorithm, and parameter.
46 * @param outputFile Destination path for the allocation result file.
47 *
48 * @pre @p interferenceGraph must be correctly built from @p webs, meaning each vertex
49 * info corresponds exactly to the `id` of a Web in @p webs.
50 *
51 * @complexity Dominated by the selected algorithm:
52 * - basic : O(V + E)
53 * - spilling : O(V + E)
54 * - splitting : O(maxSplits * (V^2 + E))
55 * - free : O(V^2 + V * N^2 * (V + E))
56 */
57 void runAllocation(
58 const Graph<int>& interferenceGraph,
59 const std::vector<Web>& webs,
60 const RegisterConfig& registerConfig,
61 const std::string& outputFile
62 );
63}
