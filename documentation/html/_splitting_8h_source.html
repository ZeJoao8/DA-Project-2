2 * @file Splitting.h
3 * @brief Declares Splitting — an iterative web-splitting register allocator.
4 *
5 * Attempts greedy graph coloring first. When coloring fails, it repeatedly:
6 * 1. Selects the highest-degree web as the split candidate.
7 * 2. Finds the optimal split point (minimum interference pressure).
8 * 3. Creates two sub-webs and incrementally updates the interference graph.
9 * 4. Retries graph coloring.
10 *
11 * This continues until coloring succeeds or the maximum number of splits is
12 * reached, at which point all webs are assigned to memory.

25/**
26 * @brief Register allocation via iterative web splitting.
27 *
28 * Attempts graph coloring first. If it fails, iteratively splits the
29 * highest-degree web at the point of minimum interference and retries
30 * coloring on the rebuilt interference graph, up to a maximum number
31 * of splits.
32 *
33 * Overall Time Complexity: O(maxSplits * (V^2 + C))
34 * where V = number of webs and C = cost of GraphColoring::run().
35 */
36class Splitting {
37public:
38 /**
39 * @brief Run register allocation with iterative web splitting.
40 *
41 * 1. Try GraphColoring::run(). If it succeeds, return immediately.
42 * 2. Otherwise, for each round i in [1..maxSplits]:
43 * a. Select the web with the highest degree in the current
44 * interference graph.
45 * b. Split it at the point of minimum interference.
46 * c. Rebuild the interference graph and retry coloring.
47 * 3. If coloring still fails after maxSplits rounds, return failure
48 * with all webs assigned to memory (-1).
49 *
50 * @param graph Initial interference graph.
51 * @param webs Original list of webs.
52 * @param numRegisters Number of available registers (K colors).
53 * @param maxSplits Maximum number of webs that can be split.
54 * @return ColoringResult with success flag and web->register mapping.
55 *
56 * Time Complexity: O(maxSplits * (V^2 + E)) where V = |webs|, E = |edges|.
57 */
58 static ColoringResult runWithSplitting(
59 const Graph<int>& graph,
60 const std::vector<Web>& webs,
61 int numRegisters,
62 int maxSplits
63 );
