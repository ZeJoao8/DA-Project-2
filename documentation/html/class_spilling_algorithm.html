double SpillingAlgorithm::calculateSpillCost ( const Web & web)
staticprivate

Calculate the spill cost for a web.

Cost is defined as (|defLines| + |useLines|). Webs that are defined and used frequently are costly to spill because each spill generates additional load/store memory operations.

Parameters
webThe web whose spill cost is computed.
Returns
Spill cost as a double (always ≥ 0).
Note
Time Complexity: O(1)

ColoringResult SpillingAlgorithm::run ( const Graph< int > & graph,
const std::vector< Web > & webs,
int numRegisters,
int maxSpills )
static

Run register allocation with spilling.

Executes the three-phase Chaitin-style allocator. The process terminates early (returning result.success = false) if more than maxSpills webs would need to be spilled.

Parameters
graphInterference graph (vertices keyed by web ID).
websAll webs to allocate.
numRegistersNumber of available physical registers (K colors).
maxSpillsMaximum number of webs that may be spilled. Allocation fails immediately if this limit is exceeded.
Returns
ColoringResult with success, numColorsUsed, webToRegister (register index or -1 for spilled webs), and spilledWebs.
Note
Time Complexity: O(V + E) where V = number of webs and E = number of interference edges (each node and edge processed O(1) times).

Select the best spill candidate using Chaitin's heuristic.

Evaluates all currently active nodes and returns the one that minimises:

Spill Cost
metric = ---------------
Active Degree

A node with a low metric is cheap to remove (low cost, many constraints resolved). Isolated nodes (degree 0) use an effective degree of 1 to avoid division by zero.

Parameters
activeSet of currently active web IDs.
webMapMap from web ID to its Web metadata pointer.
currentDegreesMap from web ID to its current active-graph degree.
Returns
ID of the best spill candidate, or -1 if active is empty.
Note
Time Complexity: O(V) where V = |active|.
