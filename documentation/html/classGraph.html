Detailed Description

template<class T>
class Graph< T >

Templated directed graph using an adjacency-list representation.

Vertices are heap-allocated and stored in vertexSet. Edges are heap- allocated inside each Vertex's adj list. The graph owns all vertex and edge memory; the destructor frees it.

In this project the graph is instantiated as Graph<int> where the int is the web ID (see GraphBuilder).

Template Parameters
TType of the info value stored in each vertex.
