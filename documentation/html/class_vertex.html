Detailed Description

template<class T>
class Vertex< T >

Represents a vertex (node) in the graph.

Stores the vertex info value, outgoing/incoming edge lists, and a set of auxiliary fields used by graph algorithms (BFS visited flag, DFS/Tarjan low-link numbers, Dijkstra distance, topological sort indegree, etc.).

Template Parameters
TType of the info value stored in each vertex.
