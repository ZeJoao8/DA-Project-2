Determines whether two webs interfere with each other.

Two webs interfere if they share at least one active line where the combination does not satisfy the exception rule (one web uses the line as its last-use point while the other defines it at the same line).

Parameters
aFirst web.
bSecond web.
Returns
true if the webs interfere and cannot share a register; false if their live ranges are completely disjoint or the overlap is entirely at adjacent use/def boundaries.
Note
Time Complexity: O(L_a + L_b) amortised due to sorted set_intersection followed by O(S) binary searches (S = |shared lines|).
