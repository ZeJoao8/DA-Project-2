Detailed Description

Templated adjacency-list graph with Vertex and Edge classes.

Provides the core data structure used throughout the project to represent the interference graph. Each vertex stores an info value of type T (here int, equal to the web ID) and a list of outgoing edges.

Originally authored by Gonçalo Leão; updated by the Francisco Lourenço, Rodrigo Roque, José Lopes.
