void BatchMode::run ( const std::string & rangesFile,
const std::string & registersFile,
const std::string & outputFile )

Execute the complete register allocation pipeline in batch mode.

Loads input files, constructs webs and the interference graph, runs the allocation algorithm specified in registersFile, and writes the result to outputFile. Any exception during loading or processing is caught and reported to stderr.

Parameters
rangesFilePath to the ranges input file (e.g., ranges.txt).
registersFilePath to the registers/algorithm config file.
outputFilePath where the allocation result will be written.
Note
Time Complexity: Dominated by AllocationEngine::runAllocation(): O(W^2 * L) for graph construction + O(V + E) to O(maxSplits * V^2) for allocation, depending on the chosen algorithm.
