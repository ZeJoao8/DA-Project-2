Detailed Description

Union-Find Disjoint Set structure with path compression and union by rank.

Supports near-constant-time set membership queries and merges. Uses path compression in findSet() and union-by-rank in linkSets() to achieve amortised O(α(N)) per operation (where α is the inverse Ackermann function — effectively O(1) in practice).

◆ linkSets()

void UFDS::linkSets ( unsigned int i,
unsigned int j )

Merges the sets containing i and j (union by rank).

If i and j are already in the same set, this is a no-op. The root with the lower rank becomes a child of the root with the higher rank. If ranks are equal, j's root becomes the new root and its rank is incremented.

iFirst element index.
jSecond element index.
Note
Time Complexity: O(α(N)) amortised.
