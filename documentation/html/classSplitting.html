Detailed Description

Register allocation via iterative web splitting.

Attempts graph coloring first. If it fails, iteratively splits the highest-degree web at the point of minimum interference and retries coloring on the rebuilt interference graph, up to a maximum number of splits.

Note
Time Complexity: O(K × V × L) where K = maxSplits, V = number of webs, L = average activeLines size per web.

Run register allocation with iterative web splitting.

  1. Try GraphColoring::run(). If it succeeds, return immediately.
  2. Otherwise, for each round i in [1..maxSplits]: a. Select the web with the highest degree in the current interference graph. b. Split it at the point of minimum interference. c. Rebuild the interference graph and retry coloring.
  3. If coloring still fails after maxSplits rounds, return failure with all webs assigned to memory (-1).
Parameters
graphInitial interference graph.
websOriginal list of webs.
numRegistersNumber of available registers (K colors).
maxSplitsMaximum number of webs that can be split.
Returns
ColoringResult with success flag and web->register mapping.
Note
Time Complexity: O(K × V × L) where V = |webs|, E = |edges|.
