Centralized algorithm dispatching, success checking, and output writing.

Always attempts basic greedy coloring first. If basic coloring succeeds, the result is written and the function returns. On failure, the algorithm specified by registerConfig.algorithmName is invoked as a fallback.

Supported fallback algorithms and their trigger condition:

  • "basic" : Reports failure; writes result with all webs in memory.
  • "spilling" : Runs Chaitin-style spilling (SpillingAlgorithm) with registerConfig.algorithmParam as the spill limit.
  • "splitting": Runs iterative web splitting (Splitting) with registerConfig.algorithmParam as the split limit.
  • "free" : Runs Kempe Chain rescue (FreeAlgorithm).
Parameters
interferenceGraphThe prebuilt interference graph (vertices = web IDs).
websList of all webs in the current allocation problem.
registerConfigConfiguration: number of registers, algorithm, and parameter.
outputFileDestination path for the allocation result file.
Precondition
interferenceGraph must be correctly built from webs, meaning each vertex info corresponds exactly to the id of a Web in webs.
Note
Time Complexity: Dominated by the selected algorithm:
  • basic : O(V + E)
  • spilling : O(V + E)
  • splitting : O(maxSplits * (V^2 + E))
  • free : O(V^2 + V * N^2 * (V + E))
