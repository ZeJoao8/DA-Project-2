26 * @brief Resolves a short filename to a full path by checking common directories.
27 *
28 * Search order:
29 * 1. The path as given (absolute or already correct relative).
30 * 2. The current working directory.
31 * 3. `../basic/<defaultDir>/<inputPath>`
32 * 4. `../../basic/<defaultDir>/<inputPath>`
33 *
34 * @param inputPath The filename or relative path to resolve.
35 * @param defaultDir Sub-directory inside `basic/` where the file typically lives
36 * (e.g., `"ranges"` or `"registers"`).
37 * @return The first path that resolves to an existing file, or the
38 * `../basic/<defaultDir>/...` fallback if none is found.
39 *
40 * @complexity O(1) — at most four filesystem probes.
41 */
42 static std::string resolvePath(const std::string& inputPath, const std::string& defaultDir);

44 /**
45 * @brief Parses the `registers.txt` configuration file.
46 *
47 * Expected format (key: value pairs, one per line; comments start with `#`):
48 * @code
49 * registers: 4
50 * algorithm: spilling, 3
51 * @endcode
52 *
53 * @param filename Path to the configuration file.
54 * @return RegisterConfig struct with numRegisters, algorithmName, and algorithmParam.
55 * @throws std::runtime_error if the file cannot be opened, is missing required
56 * fields, or contains malformed values.
57 *
58 * @complexity O(L) where L is the number of non-comment lines in the file.
59 */
60 static RegisterConfig loadRegisters(const std::string& filename);
61
62 /**
63 * @brief Parses the `ranges.txt` file to extract variable live-range points.
64 *
65 * Each non-comment line has the form:
66 * @code
67 * varName: line1+, line2, line3-, ...
68 * @endcode
69 * where `+` marks a definition and `-` marks the end of a live range.
70 * Multiple lines for the same variable create separate range segments.
71 *
72 * @param filename Path to the ranges file.
73 * @return An unordered_map from variable names to their VariableRanges data.
74 * @throws std::runtime_error if the file cannot be opened or contains
75 * malformed lines.
76 *
77 * @complexity O(L * P) where L is the number of variable lines and
78 * P is the maximum number of program points per line.
79 */
80 static std::unordered_map<std::string, VariableRanges> loadRanges(const std::string& filename);
