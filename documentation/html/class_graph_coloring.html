Detailed Description

Greedy graph coloring algorithm for register allocation.

Phase 1 - Simplification: iteratively remove nodes with degree < N onto a stack. If all remaining nodes have degree >= N, spill the highest-degree node. Phase 2 - Coloring: pop stack and assign the lowest available color not used by neighbors.

Note
Time Complexity: O(V^2) where V = number of webs.
