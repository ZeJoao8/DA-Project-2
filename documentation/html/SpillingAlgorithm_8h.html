Detailed Description

Declares SpillingAlgorithm — a Chaitin-style register allocator that explicitly spills webs to memory when necessary.

Algorithm overview:

  • Phase 0 (Init): compute active degrees; identify trivially colorable nodes.
  • Phase 1 (Simplification): remove trivial nodes (degree < K) onto a stack; when none exist, select and remove a spill candidate using Chaitin's min(cost/degree) heuristic.
  • Phase 2 (Coloring): pop nodes from the stack and assign the lowest free register color.
