static

Writes the register allocation result to a plain-text file.

Output format:

webs: <N>
web0: 1+, 2, 3-
...
registers: <K>
r0: web0
r1: web2
M: web1 # spilled to memory
Parameters
filePathDestination file path.
websList of webs written in order of their IDs.
resultColoringResult produced by an allocation algorithm.
numAvailableRegistersTotal registers the allocator was given.
Returns
true if the file was created/written successfully; false otherwise.
Note
Time Complexity: O(W * L) where W = number of webs and L = max active lines per web (due to sorting and annotation of each line).
