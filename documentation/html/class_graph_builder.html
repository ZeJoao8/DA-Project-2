Graph< int > GraphBuilder::buildInterferenceGraph ( const std::vector< Web > & webs)
static

Builds an interference Graph<int> from a list of Webs.

Each Web becomes a vertex identified by its id. For every pair returned by calculateInterferences(), a bidirectional edge of weight 1 is added to the graph.

Parameters
websThe list of Webs to build the graph from.
Returns
Graph<int> where each vertex info equals the corresponding web ID.
Precondition
The IDs of the given webs must be densely packed and strictly match the internal generation order for optimal lookup.
Note
Time Complexity: O(W^2 * L + E) where W = number of webs, L = max shared lines per pair (for interference checks), and E = number of interference edges added.

std::vector< Web > GraphBuilder::buildWebs ( const std::unordered_map< std::string, VariableRanges > & parsedData)
static

Builds Webs from parsed variable ranges using a greedy merging algorithm.

For each variable, the individual live-range segments in its VariableRanges are merged greedily: any two segments that share at least one active line are combined into a single Web. The result is a set of maximally disjoint webs for each source variable.

Parameters
parsedDataThe data parsed from ranges.txt by DataLoader::loadRanges().
Returns
std::vector<Web> A list of globally unique Webs (unique IDs starting at 0).
Precondition
parsedData must be fully populated and valid, containing no empty live ranges.
Note
Time Complexity: O(V * R^2 * L) where V = number of variables, R = maximum number of range segments per variable, and L = maximum number of active lines per segment.

std::vector< std::pair< int, int > > GraphBuilder::calculateInterferences ( const std::vector< Web > & webs)
static

Calculates interference edges between all pairs of Webs.

Two webs interfere if they share at least one active program line, unless all shared lines satisfy the exception rule: at every shared line L, one web uses L as its last-use point while the other defines L (i.e., the live ranges are adjacent, not overlapping, at L).

Parameters
websThe list of webs produced by buildWebs().
Returns
A list of (id_a, id_b) pairs representing interference edges.
Precondition
webs must have ascending unique IDs starting from 0, and each web's activeLines must be sorted.
Note
Time Complexity: O(W^2 * L) where W = number of webs and L = max number of shared active lines per pair (set intersection step).
